# Meenakshi Kalia Portfolio Website

This is a static portfolio website ready to deploy on Vercel, Netlify, or GitHub Pages.

## Deploy on Vercel

1. Go to https://vercel.com
2. Sign in with GitHub
3. Create a new GitHub repository
4. Upload these files: index.html, style.css, script.js
5. In Vercel, click Add New > Project
6. Import your GitHub repository
7. Click Deploy

For a static HTML site, Vercel can deploy this folder directly.
